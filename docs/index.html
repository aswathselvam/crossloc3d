Motivation

Representation gap between aerial and ground sources: We use the bounding box with the same color to focus on the same region and highlight the differences between aerial (left) and ground (right) LiDAR scans.

  • Scopes: The aerial scans cover a large region, while ground scans cover only a local area.
  • Coverages: The aerial scans cover the top of the buildings, while ground scans cover more details on the ground.
  • Densities: The distribution and density of the points are different because of various scan patterns, effective ranges, and fidelity of LiDARs.
  • Noise Patterns: The aerial scans have larger noises, as we can see from a bird-eye view and top-down view of a corner of the building.

Network Architecture

Architecture of our network CROSSLOC3D: Our network consists of three parts: multi-grained feature selection, iterative refinement, and NetVLAD. First, we run the points through multi-grained voxelizations and several streams of sparse convolution operations with different kernel sizes. We use feature selection to choose the best field of view and keep the corresponding features F̂i for each voxelization Vi. Second, we perform an iterative refinement process to obtain a set of local features F̄. Finally, the NetVLAD module will produce the global descriptor Fg by aggregating local features F̄.

The CS-Campus3D "Aerial + Ground" score is an average over 13 separate databases: the aerial map and 12 ground training runs. Each test query (ground runs 13–19) is matched against each database on its own, so 12 of the 13 retrievals are ground scan → ground scan. Each card overlays the retrieved scan (magenta) on the query (blue). Ground scans are stored in the sensor frame with unknown heading and per-frame scale, so the retrieved scan is fitted to the query by searching yaw, scale (0.8–1.25×) and shift. "Overlap" is the share of points within ~1.6 m of the other scan after the fit. The same fit against a random scan >300 m away is shown for reference: overlap well above it suggests the same structures, but similar numbers don't rule a match out (viewpoint and occlusion change a lot within a few metres). Scale is estimated (~79 m per unit), so metres are approximate.

Aerial-to-Aerial Retrieval

Every aerial tile (200 m × 200 m, one every ~16 m) exists twice in the evaluation files: sample _0 (set 0) and sample _1 (set 1) are two different 4096-point draws of the same tile at the same position. The paper only uses set 1 as a database for ground queries. Here each set-0 tile queries set 1, with and without its twin. All of these tiles are also training data, so this measures how well the model has fit the aerial map, not generalisation.
